# MIT-805-Big-Data-Semester-Project-2026-
MIT 805: Big Data Semester Project (2026)

## 1. Project Overview
This project analyses a large-scale historical stock market dataset containing intraday stock market observations organised by sector and stock ticker.

The analysis focuses on:
- Dataset structure and characteristics
- Data quality and preparation
- Exploratory Data Analysis (EDA)
- Trading prices and volume
- Sector-level differences
- Relationships between financial variables
- The 7 Vs of Big Data
- Potential business and financial value
- Preparation of data for MapReduce processing

The project uses a large working dataset while maintaining representation across the sectors in the original dataset.
